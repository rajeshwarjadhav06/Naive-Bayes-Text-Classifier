# 📌 Naive Bayes Text Classifier using NLP

A Machine Learning project that classifies text into multiple categories using TF-IDF Vectorization and Naive Bayes Classification. This project demonstrates the complete NLP workflow from data exploration to model evaluation and comparison.

---

## 🚀 Project Overview

This project builds a Text Classification Model using the Naive Bayes algorithm.

### Key Objectives

- Analyze and understand text data
- Transform text into numerical features using TF-IDF
- Train and evaluate a Naïve Bayes classifier
- Compare different Naïve Bayes variants
- Interpret model predictions and confidence scores
